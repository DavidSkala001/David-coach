# David Coach 🚴

Osobní AI cyklistický trenér postavený nad daty z Intervals.icu.

## Cíl projektu

David Coach je osobní AI trenér, který:

- automaticky synchronizuje data z Intervals.icu,
- analyzuje tréninky a regeneraci,
- navrhuje denní trénink,
- učí se z historie sportovce,
- pomáhá dlouhodobě zvyšovat výkonnost bez přetrénování.
