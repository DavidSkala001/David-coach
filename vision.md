# David Coach

## Cíl

Vytvořit osobního AI cyklistického trenéra, který každý den automaticky:

1. Načte data z Intervals.icu.
2. Vyhodnotí trénink a regeneraci.
3. Navrhne dnešní trénink.
4. Sleduje dlouhodobý vývoj.
5. Učí se z historie sportovce.

## MVP (verze 0.1)

- Připojení k Intervals.icu API
- Synchronizace aktivit
- Dashboard
- Denní briefing
